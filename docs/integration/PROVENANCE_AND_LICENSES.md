The Z-Anatomy source license file also lists earlier incorporated works with separate terms, including CC BY-NC-SA and CC BY-NC material. A blanket Z-Anatomy BY-SA statement is insufficient to clear every object. An object-level dependency and rights check is required for any proposed import. This is the main unresolved licensing gate. CC BY-SA obligations attach to adapted material; the exact boundary of a combined app/bundle requires a deliberate release review. Do not assert the entire MIT app must be relicensed from this audit alone.

## Files to maintain in the final project

1. Preserve `LICENSE` and `public/ATTRIBUTION.md` as existing notices; expand rather than replace them.
2. Add `ATTRIBUTION_ASSETS.md` with source authors, source URLs/DOIs, frozen revisions, exact assets, modifications and visible credits per geometry set.
3. Add `LICENSES/` containing the applicable license texts and an asset-to-license index, including any share-alike bundles and exceptions.
4. Add machine-readable `data/provenance/sources.json` and `data/provenance/assets.json` with SHA-256, upstream version, transformation pipeline, reviewers and evidence paths.
5. Include an in-app source/credits view keyed to the loaded model and supplemental set; avoid displaying a license for a geometry source that is not loaded.

Attribution validation should fail a promoted asset with missing source, hash, license ID or adaptation note. License text copied from current web pages should be pinned with access date; exact source releases take precedence over a floating branch URL.
