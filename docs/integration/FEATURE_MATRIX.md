Evidence: manifest counts were read from `public/models/atlas*.json` at the frozen tags; MVMT source and fit fields from its `atlas.json`; implementation claims from code paths above. `README.md` is corroboration only. No claim that every MVMT source-derived mesh is scientifically validated follows from `fitConfidence: high`: that is a geometric threshold, not anatomical review.

Cross-manifest integrity sampling found zero duplicate part IDs, zero duplicate concept IDs, zero missing `Concept.elements` part references and zero out-of-range chunk indices in all three wiiiimm manifests, MVMT's manifest and PR #283's manifest. MVMT retains all 2,234 male `FJ*` IDs but reclassifies 14 original BP3D parts from `skeletal` to `muscular` and two from `skeletal` to `fascia`; this is a system-label conflict even where geometry IDs match (`scripts/overrides.mjs`). PR #283 also retains all 2,234 BP3D part IDs and appends 54 `ZN*` IDs.
