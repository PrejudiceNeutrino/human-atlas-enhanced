# Human Atlas — Respiratory System Cumulative Educational Package

This archive contains **Phases 1–4**, prepared for editorial review and later implementation into Human Atlas. It has not been committed to GitHub.

- `phase-01-curriculum/`: 42-slide physiology deck, 19-slide anatomy deck, Chapter 23 study guide mapped into a five-reading curriculum and scientific review queue.
- `phase-02-readings/`: Complete General Overview (8 sections) and Deep Dive (23 sections), with structured JSON, readable Markdown, and preview.
- `phase-03-readings/`: Complete How It Connects (11 sections), Who Cares? (3 expandable stories), and Exam Cram (18 sections), with JSON, Markdown, and preview.
- `phase-04-study-tools/`: 192 glossary terms, 106 multiple-choice questions, 67 fill-in-the-blank exercises, 114 flashcards, interactive offline editorial preview, answer key, validation script, and 30-item study-guide alignment.

**Next: Phase 5.** Curate nonredundant illustrations and classroom model photographs from the two slide decks as WebP, prepare a gallery manifest, and audit exact 3D anatomical model coverage.

Every article and question is an editorial draft. The preview pages are standalone and meant for reviewing, not production iframes. See `phase-04-study-tools/scientific-review-notes.md` for important distinctions between slide shorthand and the scientific explanations.

## Phase 5 — Respiratory System Gallery and 3D Anatomy Audit
